# associacio.tallerets.com

Web institucional de l'associació Tallerets: economia social i solidària, projectes socials i transparència.
Mateix estil que tallerets.com (Astro + Tailwind, DM Sans, colors soft / dark / red).

## On s'editen els continguts
- `src/data/entitat.ts`: dades de l'entitat, principis ESS, xarxa i xifres d'impacte.
- `src/data/projectes.ts`: fitxes dels projectes socials.
- `src/pages/transparencia.astro`: documents i subvencions rebudes.

Tot el que posa `[PENDENT]` s'ha d'omplir amb dades reals.

## Ordres
- `pnpm install`
- `pnpm dev`
- `pnpm build` (genera `dist/`)
